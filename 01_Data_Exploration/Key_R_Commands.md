# Key R Commands

## Data Exploration

```r
summary(data)
```
Shows summary statistics (min, max, mean, quartiles).

```r
str(data)
```
Displays dataset structure and variable types.

```r
mean(variable)
```
Calculates average value.

```r
median(variable)
```
Calculates median value.

```r
min(variable)
```
Returns minimum value.

```r
max(variable)
```
Returns maximum value.

```r
hist(variable)
```
Creates histogram.

```r
boxplot(variable)
```
Creates boxplot to identify outliers.

```r
is.na(data)
```
Checks missing values.

```r
colSums(is.na(data))
```
Counts missing values by column.
