# Data Visualization

## Purpose

Data visualization helps identify trends, distributions, relationships, and outliers before building predictive models.

Visualization improves understanding of business and analytics datasets.

---

## Concepts Practiced

### Histogram

```r
hist(variable)
```

Purpose:

- Understand distributions
- Detect skewness
- Identify unusual patterns

---

### Boxplot

```r
boxplot(variable)
```

Purpose:

- Detect outliers
- Compare spread
- Understand variability

---

### Scatterplot

```r
plot(x,y)
```

Purpose:

- Understand relationships
- Visualize correlation
- Explore predictor variables

---

### Correlation Analysis

```r
cor(data)
```

Purpose:

- Measure relationships between variables
