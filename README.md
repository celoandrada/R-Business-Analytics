# R Business Analytics

This repository documents my R programming work in business analytics and data analysis.

## Topics Covered

- Data exploration and descriptive statistics
- Data visualization with histograms, boxplots, and scatterplots
- Cluster analysis
- Decision tree classification
- Regression analysis
- Simulation and reproducibility
- Integer programming and optimization

## Projects

### Data Exploration
Used R to inspect datasets, identify variable types, check missing values, calculate summary statistics, and analyze business datasets.

### Data Visualization
Created histograms, boxplots, and scatterplots to understand patterns, outliers, and relationships in data.

### Cluster Analysis
Used clustering methods to group candy bars based on nutritional variables such as calories, fat, protein, and carbohydrates.

### Decision Tree Classification
Built classification models to predict customer risk categories and evaluated prediction accuracy.

### Regression Analysis
Built regression models to predict outcomes such as earnings, house prices, and salaries using multiple predictor variables.

### Simulation
Used random number generation, set.seed(), sample(), and simulations to understand reproducibility and uncertainty.

### Optimization
Used integer programming to solve business decision problems involving constraints and objective functions.
